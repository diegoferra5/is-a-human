The Liveness Ladder

A bank's phone line picks up and someone starts talking. Is it a person, or a machine wearing a human voice?

Our plan · four people · thirty-six hours

The trap

The obvious move is the losing move.

We're not up against a recording played down the line. It's a robot caller that listens, thinks and speaks — improvising through a real conversation.

Everyone will train on what fake audio sounds like. But every voice engine leaves a different fingerprint, and we're graded on engines nobody has heard.

They built the split to punish memorising. Train and test share no speakers, and judging uses voices absent from both.

The idea

Stop listening to the voice. Watch the conversation.

Two ways to catch a counterfeit bill: feel the paper, or ask the person holding it a question. Everyone else feels the paper. We ask the question.

Layer 1 · Behavior

How the caller handles the flow of the call. Pause length, how much it varies, whether they ever talk over the agent.

Layer 2 · Semantic

What the caller says when the agent asks about something that does not exist.

Layer 3 · Acoustic

What the voice sounds like. It learns these engines, so we skip it — last, if at all, weighted low.

Layer 1 · Conversational behavior

Machines pause too well.

Why it works

A robot caller is three steps in a row: hear → think → speak. It physically cannot start answering until it detects you stopped talking, so its pause is always about the same length.

A person predicts where your sentence is going and jumps in early. That gap is structural — you can't remove it without breaking the agent.

What it looks like

Agent interrupts.
Person — "perdón— perdón, dígame"
Machine — clean sentence, 1.2 s later. Every time.

The consistency is the tell. Turn 3 and turn 30 look identical.

Layer 2 · Semantic

Machines can't say "I don't have that."

Why it works

A language model is built to produce a plausible answer, and it has no real account to check against — so it fills the gap.

That reflex to invent belongs to the model, not the voice. It shows up no matter which voice engine is bolted on top.

What it looks like

"¿Me confirma su cuenta Platino?"
Person — "No, yo no tengo esa cuenta."
Machine — "Sí, es la 4409-8821…"

There is no Platino account. There never was.

What we hand in

One endpoint, and a score that means something.

POST /detect
← stereo call, 8 kHz · channel 0 = caller, channel 1 = agent

{ "is_synthetic": true, "confidence": 0.87 }

We don't average the layers. Each returns a score and a flag saying whether it fired — Layer 2 only fires a few times per call. A small model learns which one to trust when, and gives us calibration for free.

The demo, and the pitch

We build the attacker, then let it get caught.

We build voice agents for a living. So we build one — with a voice engine that appears nowhere in the dataset — put it on a real phone line, and the verdict lands while the call is still going. Then a judge calls the same number and comes back human.

"We build the AI callers banks are afraid of — so we built one, called our own detector, and it caught us."
