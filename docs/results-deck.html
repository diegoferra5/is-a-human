What we refused

The unused ideas are a result too.

Breath, bleed, jitter

d ≈ 0 on 8 kHz banking audio. Room echo does not survive call conditions.

Formants

Rank high on val, point the wrong way. LPC at 8 kHz is an artifact.

Live Whisper

No transcripts. Trap questions are mostly the agent’s script. Seconds of latency.

Concatenated soup

Looks slightly higher on some previews. Collinear waits + rms_mean. We ship the honest stacked path.
